Fix now

critical

Site is not served over HTTPS

Why it matters
Browsers label HTTP pages 'Not secure' at checkout, and search engines favour HTTPS.
How to fix
Install a TLS certificate and redirect every HTTP request to HTTPS.
Evidence (1 affected)
https://fake-pies.example/

Why it matters

How to fix
